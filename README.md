# pUbo · listas

Listas de bloqueo de **pUbo**, el bloqueador de Personal Browser, en el formato de reglas de
contenido de WebKit (`WKContentRuleList`). El navegador las descarga de aquí para actualizarse sin
reinstalar.

| Fichero | Contenido |
|---|---|
| `ads-rules.json` | anuncios (genéricas + YouTube) |
| `privacy-rules.json` | rastreadores y grabación de sesiones |
| `es-rules.json` | «pUbo España»: huecos de anuncio por familia de medios |
| `listas-version.json` | número de versión de las listas |
